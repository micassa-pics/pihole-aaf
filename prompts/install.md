# Install or update Pi-hole awesome-a-fyer

1. Copy the block from the [shared prompt](manage.md) into your AI assistant.
2. Choose **The Full Monty** to select all pages and optional features. Or choose the pages and features you want. Address history and guarded saves need both DHCP and Query Log.
3. Choose **Install/update**. For a read-only check, choose **Check only**.
