# Install or update Pi-hole awesome-a-fyer

1. Copy the block from the [shared prompt](manage.md) into your AI assistant.
2. Choose **The Full Monty** for an unattended install or update of all pages and optional features. Give the assistant the target and access details. It may briefly restart Pi-hole.
3. For a custom install, choose your features and then select **Install or update**. Choose **Check only** for a read-only check. Address history and guarded saves need both DHCP and Query Log.
